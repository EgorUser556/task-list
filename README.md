# Task List

Простой список задач на React + TypeScript. Тестовое задание для позиции Junior Frontend Developer.

## Возможности

- Добавление задачи через поле ввода и кнопку (или Enter)
- Переключение задачи между выполненной и невыполненной
- Удаление задачи
- Фильтры: все, активные, выполненные
- Сохранение задач в `localStorage`: после обновления страницы они остаются
- Защита от пустых задач и задач из одних пробелов
- Выполненные задачи зачёркнуты и выделены серым цветом
- Счётчик активных задач

## Стек

- React 19 + TypeScript
- Vite
- SCSS Modules
- clsx
- OxLint, Prettier (с сортировкой импортов)
- Husky, lint-staged, commitlint (Conventional Commits)

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на адресе, который покажет Vite (обычно http://localhost:5173).
